# Oruc

Launcher pour jouer à **ta propre copie** de Fortnite 14.60 sur un serveur 100 % local.

## Installation

1. Télécharge `Oruc-Setup-x.y.z.exe` dans la dernière [release](../../releases/latest).
2. Lance-le. Windows peut afficher « Windows a protégé votre ordinateur » (l'installateur n'est pas signé) : clique sur **Informations complémentaires → Exécuter quand même**.
3. Au premier lancement, indique ton dossier Fortnite 14.60 s'il n'est pas détecté automatiquement.

Les mises à jour arrivent ensuite directement dans le launcher (bouton **« Mettre à jour »**).

## Ce qui n'est pas inclus

- **Le jeu** : Fortnite appartient à Epic Games. Il faut ton propre dossier de build 14.60.
- **Les DLL de Reboot Launcher** : elles sont téléchargées au premier lancement depuis leur dépôt officiel et vérifiées (empreinte SHA-256).

Les mentions de licence des composants tiers (Project Reboot 3.0, BSD-3-Clause) sont installées avec le launcher, dans `resources/licenses`.
